Hack The Box, sin abrir el navegador.

Máquinas, retos, sherlocks, fortress, Pro Labs, tracks, seasons, rankings, Pwnbox y VPN de Labs, desde la terminal, con la IP en vivo en cuanto HTB la asigna. Escrito tres veces: Rust, Bash y PowerShell, mismas teclas, misma carpeta, mismas funciones.

01 // lo que hace

MÁQUINAS

Activas, retiradas y sin publicar. Orden por valoración, fecha, dificultad votada, owns o nombre. Filtros de dificultad, sistema y completadas. Favoritas con una tecla. Lanzar, parar, reiniciar, extender y enviar la flag.

IP EN VIVO

Lanzas y la ficha se queda mirando: en cuanto HTB asigna la IP aparece ahí mismo, con c para copiarla. Nada de volver al menú a comprobar.

COMUNIDAD

Opiniones, actividad reciente, registro de cambios, writeup oficial, vídeo y guías de la comunidad. Búsqueda global de máquinas, retos, usuarios y equipos.

RETOS Y SHERLOCKS

Catálogo entero con categoría, dificultad, estado y orden. Zip, contenedor o los dos. Sherlocks con escenario, tareas una a una, evidencias y VM con credenciales.

SEASONS Y RANKINGS

Temporada activa con cuenta atrás, tier, leaderboard con tu puesto, recompensas. Hall of Fame de usuarios, equipos, universidades y países.

VPN Y PWNBOX

Servidores por producto, cambio del asignado, descarga del .ovpn en UDP o TCP. Estado de Pwnbox y minutos usados del plan.

FORTRESS, PRO LABS, TRACKS

Flags contra IP fija, progreso y puntos de entrada de cada Pro Lab, contenido de cada track.

SEGURIDAD

Token en un vault AES-256 con Argon2id, nunca en claro ni en argv. Se niega a correr como root. Sin OSC 52, sin instalar nada por su cuenta, sin llamar a nadie que no sea HTB.

03 // instalar

rust, la recomendada
$ git clone https://github.com/Aztharot-RO0t3t/htb-suite $ cd htb-suite/rust/htb-cli $ cargo build --release $ install -m 755 target/release/htb ~/.local/bin/htb $ htb token --set pega tu App Token, elige passphrase $ htb interfaz completa
bash y powershell
$ bash ./htb.sh necesita bash 4, curl, jq, openssl, python3, xxd PS> pwsh -File ./htb.ps1 PowerShell 7 en Linux, macOS o Windows

El App Token se crea en la web de HTB, en el perfil, apartado App Tokens. Se guarda cifrado en ~/.config/htb-hfc/token.vault y se descifra en memoria con tu passphrase al arrancar.
